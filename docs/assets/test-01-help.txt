Usage of ./dbexplain:
  -config string
    	JSON config file with array of DSNs
  -dsn value
    	...
  -env
    	use .env file (prefix DB1=, DB2=...)
  -exclude string
    	comma-separated kinds/labels/env-keys to exclude (e.g. mongodb,qdrant or DB5)
  -include string
    	comma-separated kinds/labels/env-keys to include (e.g. mysql,redis or DB1,DB3)
  -json
    	output JSON
  -o string
    	write output to file
  -timeout duration
    	per-DSN collect timeout (default 20s)
