重磅一

01配置文件硬件绑定加密

这是本次发布最核心的安全特性。v0.0.6 新增 encrypt 子命令，将数据库密码与机器硬件指纹绑定加密。加密后的 .enc 文件，离开了这台机器就无法解密——即使攻击者拿到文件也没用。

加密技术栈
算法  XChaCha20-Poly1305 (AEAD) ← 认证加密，防篡改
密钥派生 SHA-256（机器指纹哈希）
迭代次数 PBKDF2-HMAC-SHA256 × 100,000 ← 密码增强模式
文件权限 0600
CGO   CGO_ENABLED=0 ← 全平台纯 Go 编译

使用极其简单，三步完成

1
加密明文配置：dbexplain encrypt ~/.config/dbexplain/.env.dbexplain
2
删除明文文件：rm ~/.config/dbexplain/.env.dbexplain（这步不能省！）
3
正常使用：dbexplain -env，工具自动发现 .enc 文件并解密，对用户完全透明
加密后务必删除明文 .env.dbexplain 文件，否则工具会优先匹配明文文件，加密形同虚设。

机器指纹跨平台采集：Linux 读 /etc/machine-id，macOS 读 sysctl hw.uuid，Windows 读注册表 MachineGuid。各数据源独立采集，多重兜底。

还支持密码增强模式——密码 + 机器指纹双重保护。密码写入 .encryption_key 文件（权限 600），运行时自动读取，同样无需人工干预。

重磅二

02CLI 子命令层级重构

原来的命令行是扁平的参数堆，用过的人都懂那种感受——-h 出来密密麻麻一页，完全不知道从哪下手。这次彻底重构为清晰的子命令结构：

# 新命令结构
dbexplain [flags]           # 采集和分析数据库 Schema
dbexplain encrypt <file>    # 加密 .env 配置
dbexplain <dbtype>          # 数据库专用参考手册
dbexplain all               # 完整参考手册（替代 --manual）
dbexplain all --filter redis # 关键词过滤

每种数据库现在有独立子命令，输出该数据库专属的参考手册（DSN 格式、采集机制、安全策略、完整示例）：

dbexplain mysql       # MySQL 专属手册
dbexplain redis       # Redis 专属手册
dbexplain es          # Elasticsearch（别名 es）
dbexplain pg          # PostgreSQL（别名 pg）
重磅三

03一键安装，开箱即用

过去需要把二进制和配置文件放在同一目录，在 CI/CD 或多环境下非常麻烦。现在一条命令搞定全局安装 + AI Skill 部署：

# 克隆并安装（Linux/macOS）
git clone https://github.com/IamWWT/dbexplain.git
cd dbexplain
bash dbexplain-skill/scripts/install.sh

# 安装英文 Skill 版本
bash dbexplain-skill/scripts/install.sh --lang en

# Windows PowerShell
.\dbexplain-skill\scripts\install.ps1

安装后 dbexplain 直接进系统 PATH，配置文件按 XDG 规范存放在 ~/.config/dbexplain/。安装脚本完成后自动引导用户执行加密三步曲。

Skill 同时拆分为 SKILL_ZH.md（中文）和 SKILL_EN.md（英文），适配 Claude Code、DeepSeek、AixCoding 等平台。

工具定位

04它到底解决什么问题？

一句话：让 AI Agent 读懂你的数据库，同时不暴露任何秘密。

当你问 Claude Code "帮我优化这条 SQL" 或者 "分析用户表和订单表的关系"，AI 需要先理解数据库结构。传统做法是把 Schema DDL 手动粘贴给 AI——繁琐、容易遗漏、还可能带上密码。

dbexplain 的工作流是：只读扫描 → 生成结构上下文（JSON 或文本） → 喂给 AI Agent。全程不需要 AI 接触任何连接凭证。

# 扫描所有数据源，输出 AI 友好的 JSON 上下文
dbexplain -env -json

# 生成压缩的 AI 上下文文件
dbexplain -env --context ./ai-context/

# 增量检测 Schema 变更
dbexplain -env --cache schema_cache.json

写在最后

在 Agentic AI 快速落地的当下，安全往往是最后被考虑的环节。dbexplain 的这次更新，实际上是在回答一个更大的问题：

当 AI Agent 需要与生产数据库交互时，凭证管理的最佳实践是什么？

硬件绑定加密给出了一个务实的答案：不依赖复杂的密钥管理基础设施，不增加运维负担，让密码天然绑定在它该存在的机器上。
